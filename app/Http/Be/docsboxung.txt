2. Người chia sẻ
Chức năng:
Xóa thành viên khỏi hệ thống
Điều kiện:
Có quyền quản lý tuyến dưới

3. Khách hàng report F1
Chức năng:
Khách hàng có thể report người giới thiệu (F1)
Sau khi report:
Admin xem xét
Có quyền xóa F2 khỏi F1
Chuyển tuyến hệ thống nếu cần

4. Nhóm API cho Người chia sẻ (User/Affiliate)
Chú ý:
- Các API yêu cầu đăng nhập `auth:sanctum` và giới hạn tần suất để chống spam.
- "F1" = tuyến giới thiệu trực tiếp của người báo cáo/affiliate hiện tại.

API User/Affiliate:
1) GET /api/affiliate/links
- Lấy danh sách link sản phẩm, link cửa hàng và Name card giới thiệu của user hiện tại.

2) GET /api/affiliate/downline?depth=5
- Lấy danh sách thành viên tuyến dưới (F1, F2...) kèm doanh số họ tạo ra (đang dùng thống kê từ orders/commission_users theo logic hiện có).

3) DELETE /api/affiliate/downline/{userId}
- Xóa/Detach 1 thành viên khỏi tuyến dưới của user hiện tại (chỉ người có quyền quản lý tuyến dưới được phép).
- Thực hiện theo hướng "detach" để không làm đứt gãy lịch sử hoa hồng.

4) POST /api/affiliate/report-uplline
- F2 gửi report khiếu nại về người giới thiệu trực tiếp (F1/upline).
- Backend tạo record ở bảng `complaints` với `complaint_type = affiliate_dispute` và kèm 1 message đầu tiên.
